# pytorch_2024

2024 年的周笔记，比 `pytorch_2025` 更短，适合先看模型大概长什么样。

- `practise_1_getstarted.ipynb`：Fashion-MNIST。
- `week2/practise_1_linear_regression_scratch.ipynb`：从零线性回归。文件原先在 `tensorflow/week2`，因为内容是 PyTorch，所以移到这里，并补上了小批量梯度下降。
- `week3/`：MLP、CNN、RNN、LSTM、一个简单 Transformer，以及 ReLU 数值爆炸的演示。`practise_4_cnn.ipynb` 原来是空文件，现在是一个合成数据上的小卷积网络。
- `week4/`：用 `poems.txt` 做字符级文本，以及图像扩散的两份笔记。

`model.safetensors` 是入门笔记保存的权重，已从仓库删除，运行笔记时会重新写出。
