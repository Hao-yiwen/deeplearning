# tensorflow

- `week2/practise_1_linear_regression.ipynb`：TensorFlow 线性回归和向量计时。

`week2` 里另外两份文件名像线性回归的笔记并不是 TensorFlow：一份几乎是空的，已删除；另一份是 PyTorch 草稿，现位于 `pytorch_2024/week2/`。

安装：

```bash
pip install -r requirements-tensorflow.txt
```
